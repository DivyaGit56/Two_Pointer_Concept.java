# 👉👈 Two Pointer Repository

Welcome to my **Two Pointer** repository! This repository contains a collection of Two Pointer technique problems implemented primarily in **Java**. It is designed to help beginners understand the two-pointer approach and master interview-level problems involving arrays, strings, and linked lists.

---

# 📖 About

The **Two Pointer** technique is an efficient algorithmic approach that uses two indices (pointers) to traverse a data structure. It helps optimize solutions by reducing the need for nested loops, often improving time complexity from **O(n²)** to **O(n)**.

This repository includes:

* ✅ Beginner-friendly two pointer problems
* ✅ Array, String, and Linked List problems
* ✅ Pattern-based interview questions
* ✅ Well-commented Java implementations
* ✅ Time and Space Complexity analysis
